# HOMYAK (H.A.M.S.T.E.R.)

Х.А.М.С.Т.E.Р — это современная платформа для общения, созданная для скорости, удобства и свободы коммуникации.

## Это не просто мессенджер. Это связь. 
   
#### Чем HOMYAK лучше MAX?
- 💅 Ловит даже на Марсе (из задач WEB 1) 💅  
- 💅 MAX хранит ключи у себя — Хомяк грызёт твои данные. Ключей нет((( 💅   
- 💅 Если вам напишет мошенник, то хомяк схомячит его! Во! А в MAX такого хомячка нету((( 💅   
- 💅 Если MAX — это ГАЗ-69, то HOMYAK — это Mercedes-Benz G-Class. 💅   

#### 😍Чем HOMYAK лучше медной проволоки со стаканчиками?😍
- 🎯 У стаканчика звук консервной банки, а у Х.А.М.С.Т.E.Р звук, как будто Хомяк залез тебе прямо в ухо и шепчет: «Купи гречки». И ты покупаешь.  
- 🎯 Стаканчик размокает от дождя. Хомяк не мокнет. Хомяк — Сила!  
- 🎯 Стаканчик — позвонил, и тебя слышно. Хомяк — позвонил, и тебя видно. Камера не нужна.  
- 🎯 Проволока медная — её утащили на цвет. мет, а Хомяка утащить нельзя. Он сам тебя утащит.

## 🚀 Как запустить своего Хомяка? 
> 😰 Скачиваем путхон 3.13+ (с включенным path)😭  
> 😰 Скачиваем ноде хс😭  
> 🚀и пошло, поехало W🚀  

```
git clone https://github.com/Crypto-Homyak/HOMYAK.git

cd HOMYAK

pip install -r requirements.txt

cd templates/hamster

npm i

npm run build

cd ../..
```

> Запускаем:
```
# Windows:
./windows-run-server.bat

# Linux/MacOs:
chmod +x unix-run-server.sh
./unix-run-server.sh
```
